# GitHub Upload

This folder is the clean public research package for the thesis.

1. Create a new GitHub repository.
2. Use GitHub Desktop, or upload this folder as the repository root.
3. Review the contents before the first commit.
4. Do not add the local Data/01_Raw, Data/02_Processed or Data/03_Rebuild directories.
5. Keep the provenance manifest with the repository so restricted local inputs remain traceable.

The package contains the final thesis, research-pipeline code, compact final empirical results, audit files, figures and reproducibility documentation.

Large quote-level and vendor-restricted datasets remain local and are documented rather than redistributed.
