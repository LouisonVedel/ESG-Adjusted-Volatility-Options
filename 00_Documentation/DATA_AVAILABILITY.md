# Data Availability

The repository documents the complete empirical provenance without redistributing restricted vendor data.

Option data are sourced from OptionMetrics. Equity and market-data fields are sourced through Refinitiv Eikon / LSEG. The LSEG forward price is used directly in Black-76.

Restricted/raw files remain in the local thesis data tree. The provenance manifest records their relative paths, sizes and SHA-256 hashes where practical. Compact final summaries and reproducibility code are included here.

Large quote-level and merged datasets remain local because they contain vendor-derived fields and are unsuitable for public redistribution.
